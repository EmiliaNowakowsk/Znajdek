# Znajdek — prototypy interfejsu

## Cel
Prototypy przedstawiają koncepcję systemu zgłaszania i wyszukiwania
zgubionych oraz znalezionych przedmiotów na uczelni.

## Prototyp 1 — wstępny
Prosty układ strony z wyszukiwarką, listą przykładowych zgłoszeń
oraz formularzem umożliwiającym podgląd nowego zgłoszenia.

## Prototyp 2 — rozwinięty
Ulepszony wygląd interfejsu, filtrowanie po uczelni i rodzaju zgłoszenia,
podgląd szczegółów przedmiotu oraz rozbudowany formularz.

## Charakter prototypów
Prototypy mają charakter demonstracyjny. Korzystają z przykładowych
danych i nie zapisują zgłoszeń w bazie danych ani nie komunikują się
z backendem.

## Uruchomienie
Otwórz plik `index.html` z wybranego folderu prototypu w przeglądarce.
